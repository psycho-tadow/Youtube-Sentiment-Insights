Under the hood

A small model,
run like production software.

Signal isn't just a script that calls a model. It's a full pipeline — data, training, tracking, and deployment — wired together so a new model can ship without anyone touching a server by hand.

The pipeline

Comments in

The browser pulls comments straight from the YouTube Data API — no scraping, no stored video data.

→
Preprocessing

Text is lowercased, cleaned, and lemmatized — stripped down to the words that carry sentiment.

→
Model scoring

A TF-IDF vectorizer feeds a trained classifier that scores each comment positive, neutral, or negative.

→
Served results

Flask returns the scores plus rendered charts — pie split, word cloud, and a monthly trend line.

How it's tracked and shipped

Experiment tracking

Model versions and metrics are logged and registered with MLflow, so the exact model in production is always traceable back to the run that trained it.

Data & model versioning

Datasets and pipeline stages are versioned with DVC, keeping training reproducible instead of one-off.

CI/CD

GitHub Actions runs tests and builds on every push, so a broken change never quietly reaches production.

Deployment

The Flask API is containerized and deployed to an AWS EC2 instance, serving predictions over a simple HTTP interface.
